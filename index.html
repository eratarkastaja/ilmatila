AIRCRAFT 3D MODEL

FlightGear F-35B

The aircraft model is based on the FGMEMBERS/F-35B project. Original contributors: Petar Jedvaj, Detlef Faber, F-GTUX, Stuart Cassie and Gary Brown. The game uses an F-35B model to represent the F-35A; it is not an F-35A-specific model.
