# Changelog

## 0.1.0-alpha.1 — 2026-09-29

Initial public alpha. This release packages the browser game, FlightGear-derived aircraft model and source, English and Finnish interface, four mission profiles, simulated air and ground combat, and optional tooling for generating local Finnish terrain packages.

The game is an early prototype. Flight, weapons, radar, AI, and battlefield behavior are simplified simulations.
