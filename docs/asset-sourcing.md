## Download and attribution handling

Sketchfab's [download API guidelines](https://sketchfab.com/developers/download-api/guidelines) state that model downloads require an authenticated Sketchfab account and that reuse must clearly credit both the author and Sketchfab and identify the license. Do not use third-party mirrors or model rips as substitutes. Keep each chosen source archive, license text, attribution, and conversion notes together with the optimized game asset.

The NPS archive states that its open-source model license permits commercial and non-commercial use. Binary redistribution must include the copyright notice, license conditions, and disclaimer in documentation or other distribution materials. The license does not allow using the Web3D Consortium's name or contributors to endorse the game.
